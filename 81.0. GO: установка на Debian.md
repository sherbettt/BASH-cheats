# Установка нескольких версий Go на Debian 13

| 🟡 **NOTICE** |
|----------------|
| ВАЖНО! Ниже указанные действия применять только на Debian13 |

---

## 📖 Введение: Два разных GVM

Существует **два совершенно разных инструмента** с одинаковым названием GVM (Go Version Manager):

| Характеристика | `moovweb/gvm` (классический) | `tfournier/gvm` (альтернативный) |
|:---|:---|:---|
| **Установка** | Через bash-скрипт | Через `go install` |
| **Принцип работы** | Компилирует Go из исходников | Скачивает готовые бинарники |
| **Скорость** | Медленно (10-30 мин) | Быстро (секунды) |
| **Безопасность** | Может изменять системные файлы | Работает в домашней директории |
| **Риск для системы** | Высокий | Низкий |
| **Где используется** | Исторически первый GVM | Современная альтернатива |

### ⚠️ Важное предупреждение

**`moovweb/gvm` может сломать систему!** Известны случаи, когда его установка повреждала графическую оболочку (GDM) и делала невозможным вход в систему. Особенно это опасно на дистрибутивах с графическим интерфейсом (Ubuntu, Linux Mint, Ximper и др.).

**Для Debian 13 рекомендуется использовать `tfournier/gvm`** как более безопасный и современный инструмент.

## 🔧 Часть 1: Ручная установка Go (базовый способ)

Смотрим [доступные версии GO](https://go.dev/dl/) и качаем.

```bash
cd /usr/local/
wget https://go.dev/dl/go1.25.1.linux-amd64.tar.gz
tar -xvf go1.25.1.linux-amd64.tar.gz
```

Редактируем **`/etc/profile`**, добавляя вниз:
```ini
export PATH=$PATH:/usr/local/go/bin
echo 'export PATH=$PATH:/usr/local/go/bin' | sudo tee -a /etc/profile
#echo 'export PATH=$PATH:/usr/local/go/bin' | sudo cat >> /etc/profile
#printf '\nexport PATH=$PATH:/usr/local/go/bin\n' | sudo tee -a /etc/profile
```

И один раз выполняем данную команду:
```bash
export PATH=$PATH:/usr/local/go/bin
```

Проверяем:
```sh
root@app /usr/local/go
14:04:20 # go version
go version go1.25.1 linux/amd64
```

## 🛠️ Часть 2: Установка GVM от tfournier (РЕКОМЕНДУЕТСЯ)

Подтверждение от разработчиков: https://pkg.go.dev/github.com/tfournier/gvm#section-readme

### 2.1 Установка Go (если ещё не установлен)

```bash
sudo apt update -y
sudo apt install -y golang-go
```

### 2.2 Установка GVM через go install

```bash
go install github.com/tfournier/gvm@latest
```

### 2.3 Настройка PATH

Добавьте в `~/.bashrc`:
```bash
echo 'export PATH=$PATH:$HOME/go/bin' >> ~/.bashrc
source ~/.bashrc
```

### 2.4 Проверка установки

```bash
gvm --version
# или
gvm help
```

### 2.5 Работа с tfournier/gvm

#### Установка версий Go

```bash
# Установка конкретной версии
gvm install 1.23.4

# Установка нескольких версий
gvm install 1.22.0
gvm install 1.24.0

# Установка последней стабильной версии
gvm install latest
```

#### Просмотр установленных версий

```bash
gvm list
```

Вывод:
```
Installed versions:
  1.22.0
  1.23.4
  1.24.0
```

#### Переключение между версиями

```bash
# Временное переключение
gvm use 1.23.4

# Проверка текущей версии
go version
# go version go1.23.4 linux/amd64

# Сделать версию по умолчанию
gvm alias default 1.24.0
```

#### Удаление версии

```bash
gvm uninstall 1.22.0
```

#### Обновление GVM

```bash
go install github.com/tfournier/gvm@latest
```

### 2.6 Быстрые команды для tfournier/gvm

| Действие | Команда |
|----------|---------|
| Установить версию | `gvm install X.Y.Z` |
| Посмотреть установленные версии | `gvm list` |
| Временно переключиться | `gvm use X.Y.Z` |
| Сделать версию по умолчанию | `gvm alias default X.Y.Z` |
| Проверить текущую версию | `go version` |
| Удалить версию | `gvm uninstall X.Y.Z` |
| Обновить GVM | `go install github.com/tfournier/gvm@latest` |

## 🛠️ Часть 3: Установка GVM от moovweb (КЛАССИЧЕСКИЙ, НО ОПАСНЫЙ)

> ### 🛑 NOTICE
>
> Данный скрипт не предназначен для установки на ALT-based ОС!
> **Внимание!** Может сломать систему!

### 3.1 Установка зависимостей

```bash
sudo apt update -y
sudo apt install -y curl git mercurial make binutils bison gcc build-essential
```

### 3.2 Установка GVM

```bash
bash < <(curl -s -S -L https://raw.githubusercontent.com/moovweb/gvm/master/binscripts/gvm-installer)
```

После выполнения вы увидите сообщение:
```
Cloning from https://github.com/moovweb/gvm.git to /root/.gvm
No existing Go versions detected
Installed GVM v1.0.22
```

### 3.3 Настройка окружения

Добавьте GVM в автозагрузку при каждом входе в систему:

```bash
echo '[[ -s "$HOME/.gvm/scripts/gvm" ]] && source "$HOME/.gvm/scripts/gvm"' >> ~/.bashrc
source ~/.bashrc
```

**Важно:** Проверьте, что строка добавлена только один раз, чтобы избежать дублирования:

```bash
grep "gvm" ~/.bashrc
```

Если строка продублировалась, удалите лишнюю через редактор:
```bash
mcedit ~/.bashrc   # или nano ~/.bashrc
```

### 3.4 Работа с moovweb/gvm

#### Установка из бинарных файлов (рекомендуется)

GVM по умолчанию компилирует Go из исходников, что занимает много времени и может зависнуть. **Используйте флаг `-B`** для установки из готовых бинарников:

```bash
# Установка конкретной версии (примеры)
gvm install go1.19.8 -B
gvm install go1.23.4 -B
gvm install go1.24.0 -B
```

**Внимание:** Если вы указываете версию, которой не существует (например, go1.26.5), установка завершится с ошибкой. Проверяйте актуальные версии на [официальном сайте Go](https://go.dev/dl/).

#### Альтернативный способ: установка из исходников (медленно)

Если вам нужна кастомная сборка или у вас нет доступа к бинарникам:

```bash
gvm install go1.19.8
```

**Предупреждение:** Этот процесс может занять 10-30 минут и часто подвисает. **Рекомендуется использовать флаг `-B`.**

#### Просмотр установленных версий

```bash
gvm list
```

Вывод должен показывать все установленные версии:
```
gvm gos (installed)

   go1.19.8
   go1.23.4
   go1.24.0
```

#### Переключение между версиями

**Временное переключение (для текущей сессии):**

```bash
gvm use go1.23.4
```

После этого проверьте версию:
```bash
go version
# go version go1.23.4 linux/amd64
```

**Установка версии по умолчанию:**

```bash
gvm use go1.24.0 --default
```

Теперь при каждом новом открытии терминала будет использоваться эта версия.

**Переключение для конкретного проекта:**

Перейдите в директорию проекта и установите локальную версию:

```bash
cd /path/to/your/project
gvm use go1.19.8
```

GVM запомнит эту версию для текущей директории, и при переходе в неё версия будет меняться автоматически.

#### Удаление версии

```bash
gvm uninstall go1.19.8
```

#### Обновление GVM

```bash
gvm update
```

### 3.5 Быстрые команды для moovweb/gvm

| Действие | Команда |
|----------|---------|
| Установить версию из бинарника | `gvm install goX.Y.Z -B` |
| Посмотреть установленные версии | `gvm list` |
| Временно переключиться | `gvm use goX.Y.Z` |
| Сделать версию по умолчанию | `gvm use goX.Y.Z --default` |
| Проверить текущую версию | `go version` |
| Удалить версию | `gvm uninstall goX.Y.Z` |
| Обновить GVM | `gvm update` |

## ⚠️ Часть 5: Важные замечания и устранение проблем

### 5.1 Избегайте системного пакета golang-go

Не устанавливайте Go через `apt install golang-go`, так как он может конфликтовать с GVM. Если пакет уже установлен:

```bash
sudo apt remove golang-go
```

### 5.2 Команда `go` не найдена после установки GVM

Если после установки GVM команда `go` не работает:

1. Убедитесь, что вы выполнили `source ~/.bashrc`
2. Проверьте, что GVM загружен:
   ```bash
   type gvm
   # должно показывать: gvm is a function
   ```
3. Перезапустите терминал или выполните:
   ```bash
   exec $SHELL
   ```

### 5.3 Установка зависла на "Downloading Go source..."

Прервите процесс (Ctrl+C) и используйте бинарную установку с флагом `-B`:

```bash
gvm install go1.24.0 -B
```

### 5.4 Ошибка "No system Go version detected"

Это нормально для свежей установки GVM. Просто установите версию Go через GVM.

### 5.5 Некорректное отображение версии

Если `go version` показывает не ту версию, которую вы выбрали через `gvm use`:

1. Проверьте, что нет конфликтов в `PATH`:
   ```bash
   which go
   # должно показывать путь внутри /root/.gvm/ (для moovweb)
   # или /root/go/bin (для tfournier)
   ```
2. Перезагрузите сессию: `exec $SHELL`

## 💡 Рекомендации

1. **Для Debian 13 используйте `tfournier/gvm`** — он безопаснее и быстрее
2. **Избегайте `moovweb/gvm` на системах с GUI** — есть риск поломки
3. **Ручная установка** (через `/usr/local/`) — самый безопасный способ
4. **Всегда делайте бэкап** перед установкой системных инструментов
