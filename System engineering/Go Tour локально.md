## Установка локальной версии Go Tour

### ▎Шаг 1. Проверьте установку Go

Убедитесь, что Go установлен и работает:
```bash
go version
```
**Ожидаемый вывод:** что-то вроде `go version go1.xx.x linux/amd64`

Если Go не установлен, скачайте его с [официального сайта](https://go.dev/dl/) и установите.

---

### ▎Шаг 2. Установите тур

Выполните команду:
```bash
go install golang.org/x/website/tour@latest
```

**Что произойдёт:**
- Бинарный файл `tour` будет загружен и скомпилирован
- Установится в папку `$GOPATH/bin` (обычно `~/go/bin`)

Если вы видите ошибки прав доступа, используйте:
```bash
GOPATH=$HOME/go go install golang.org/x/website/tour@latest
```

---

### ▎Шаг 3. Найдите установленный бинарник

Проверьте, что файл появился:
```bash
ls -la ~/go/bin/tour
```

Если файл есть — переходите к шагу 4.  
Если нет — проверьте, куда Go устанавливает бинарники:
```bash
go env GOPATH
```
И посмотрите в папке `bin` внутри этого пути.

---

### ▎Шаг 4. Запустите тур

Запустите бинарник:
```bash
~/go/bin/tour
```

**Что произойдёт:**
- Терминал покажет сообщение о запуске сервера
- Автоматически откроется браузер с адресом `http://localhost:3999`
- Вы увидите точно такую же страницу, как на `https://go.dev/tour/list`

Если браузер не открылся, откройте его вручную и перейдите по адресу:
```
http://localhost:3999
```

---

### ▎Шаг 5. Настройте быстрый запуск (опционально)

Чтобы запускать тур командой `tour` из любого места, добавьте `~/go/bin` в `PATH`.

Откройте файл `~/.bashrc`:
```bash
micro ~/.bashrc
```

Добавьте в конец файла:
```bash
export PATH=$PATH:~/go/bin
```

Сохраните (`Ctrl+O`, затем `Enter`) и выйдите (`Ctrl+X`).  
Примените изменения:
```bash
source ~/.bashrc
```

Теперь можно запускать тур просто:
```bash
tour
```

---

### ▎Шаг 6. Проверьте работу

1. В браузере перейдите на `http://localhost:3999/list`
2. Вы увидите полный список уроков:
   - Using the tour
   - Basics
   - Methods and interfaces
   - Generics
   - Concurrency
3. Нажмите на любой урок — код будет компилироваться и запускаться **локально, без интернета**

---

### ▎Шаг 7. Остановка тура

Чтобы остановить локальный сервер, нажмите в терминале:
```
Ctrl+C
```

---

✅ Полный доступ ко всем модулям тура

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| `command not found: go` | Установите Go с [официального сайта](https://go.dev/dl/) |
| `tour: command not found` | Запускайте через полный путь: `~/go/bin/tour` или настройте `PATH` |
| Порт 3999 занят | Тур выберет другой порт автоматически, проверьте сообщение в терминале |
| Браузер не открылся | Откройте вручную `http://localhost:3999` |
| Ошибка `go: cannot find main module` | Это нормально, `go install` работает без модуля |
