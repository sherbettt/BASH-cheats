## Что мы сделали (кратко, с комментариями)

### 1. Перешли в директорию проекта
```bash
cd /opt/runtel/rcreview
```
> Это рабочая директория приложения `rcreview`.

---

### 2. Активировали виртуальное окружение
```bash
source .venv/bin/activate
```
> В Python принято изолировать зависимости проекта от системных. `.venv` — это виртуальное окружение.  
> `source` активирует его, чтобы все команды и пакеты использовались именно из этой папки.

---

### 3. Установили проект в режиме разработки
```bash
pip install -e '.[dev]'
```
> `-e` (editable) — означает, что код не копируется, а используется из текущей папки (удобно для разработки).  
> `.[dev]` — устанавливает проект + все зависимости для разработки (тесты, линтеры, etc.).

---

### 4. Настроили переменные окружения
```bash
cp .env.example .env
```
> В `.env` хранятся настройки: база данных, пароли, порты, режим работы.  
> Мы скопировали пример и (предположительно) отредактировали его под свои нужды.

---

### 5. Применили миграции базы данных
```bash
rcreview-migrate upgrade head
```
> Миграции — это изменения структуры БД.  
> `upgrade head` означает «накатить все последние изменения». Без этого приложение не сможет работать с данными.

---

### 6. Запустили API-сервер
```bash
rcreview-api
```
> Это FastAPI-приложение, которое слушает порт **8080**.  
> Оно обслуживает веб-интерфейс и API.

---

### 7. Запустили воркер (в другом терминале)
```bash
rcreview-worker
```
> Воркер обрабатывает фоновые задачи (например, анализ кода, отправку уведомлений).  
> Мы запустили его, но потом остановили через `Ctrl+C` для простоты.

---

### 8. Узнали IP-адрес сервера
```bash
ipc
```
> Команда показала, что сервер доступен по адресу `192.168.97.152`.  
> Это нужно, чтобы понять, на каком адресе открывать приложение.

---

### 9. Сделали SSH-туннель
```bash
ssh -L 8080:127.0.0.1:8080 root@192.168.97.152
```
> Туннель — это проброс порта.  
> Всё, что вы отправляете на `localhost:8080` на своём ноутбуке, перенаправляется на `127.0.0.1:8080` на сервере.  
> **Зачем**: интерфейс работает на сервере, но мы хотим открыть его в браузере у себя.

---

### 10. Открыли в браузере
```
http://localhost:8080
```
> Браузер обращается к локальному порту 8080.  
> SSH перенаправляет запрос на сервер, где его принимает `rcreview-api`.  
> Сервер возвращает страницу логина.
