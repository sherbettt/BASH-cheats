## Часть 1. Установка сертификатов в систему

### Шаг 1. Переход в папку с сертификатами

Откройте терминал и перейдите в директорию, куда вы скачали сертификаты:

```bash
cd /home/kkorablin/Загрузки/Certs_mincifra/
```

### Шаг 2. Копирование сертификатов в системное хранилище

Скопируйте все необходимые сертификаты в папку доверенных корневых сертификатов:

```bash
sudo cp russian_trusted_root_ca_pem.crt /etc/ca-certificates/trust-source/anchors/
sudo cp russian_trusted_root_ca_gost_2025_pem.crt /etc/ca-certificates/trust-source/anchors/
sudo cp russian_trusted_sub_ca_pem.crt /etc/ca-certificates/trust-source/anchors/
sudo cp russian_trusted_sub_ca_2024_pem.crt /etc/ca-certificates/trust-source/anchors/
sudo cp russian_trusted_sub_ca_gost_2025_pem.crt /etc/ca-certificates/trust-source/anchors/
```

**Важно:** Файлы с расширением `.zip` копировать не нужно, это архивы, внутри которых находятся те же сертификаты.

### Шаг 3. Обновление системного хранилища

Выполните команду для применения изменений:

```bash
sudo update-ca-trust
```

### Шаг 4. Проверка установки

Убедитесь, что сертификаты успешно добавлены:

```bash
trust list | grep -i russian
```

Вы должны увидеть список всех установленных российских сертификатов.

## Часть 2. Удаление сертификатов из системы

Если вы хотите удалить сертификаты из системного хранилища и оставить их только в браузерах:

### Шаг 1. Удаление файлов сертификатов

```bash
sudo rm /etc/ca-certificates/trust-source/anchors/russian_trusted_root_ca_pem.crt
sudo rm /etc/ca-certificates/trust-source/anchors/russian_trusted_root_ca_gost_2025_pem.crt
sudo rm /etc/ca-certificates/trust-source/anchors/russian_trusted_sub_ca_pem.crt
sudo rm /etc/ca-certificates/trust-source/anchors/russian_trusted_sub_ca_2024_pem.crt
sudo rm /etc/ca-certificates/trust-source/anchors/russian_trusted_sub_ca_gost_2025_pem.crt
```

**Альтернативный способ** — удалить все сертификаты Минцифры одной командой:

```bash
sudo rm /etc/ca-certificates/trust-source/anchors/russian_trusted_*.crt
```

### Шаг 2. Обновление системного хранилища

После удаления файлов необходимо обновить хранилище, чтобы система перестала их использовать:

```bash
sudo update-ca-trust
```

### Шаг 3. Проверка удаления

Убедитесь, что сертификаты больше не отображаются в системном списке:

```bash
trust list | grep -i russian
```

Команда не должна выдать никаких результатов.

**Важно:** После удаления сертификатов из системы браузеры на базе Chromium (Chrome, Edge, Opera, Vivaldi, Brave) перестанут видеть эти сертификаты. Чтобы они продолжали работать, нужно добавить сертификаты вручную в каждый браузер (см. Часть 3). Firefox использует собственное хранилище, поэтому удаление системных сертификатов на него не повлияет, если вы уже импортировали их туда ранее.

## Часть 3. Настройка браузеров (ручной импорт)

Если вы удалили сертификаты из системы, вам нужно добавить их в каждый браузер вручную.

### Браузеры на базе Chromium (Google Chrome, Opera, Vivaldi, Brave, Edge)

#### Инструкция для Chromium-браузеров:

1. Откройте браузер.
2. В адресной строке введите:
   - Для Chrome: `chrome://settings/certificates`
   - Для Edge: `edge://settings/certificates`
   - Для Opera: `opera://settings/certificates`
   - Для Vivaldi: `vivaldi://settings/certificates`
   - Для Brave: `brave://settings/certificates`
3. Нажмите Enter.
4. Перейдите на вкладку **"Центры сертификации"** (Authorities).
5. Нажмите кнопку **"Импорт"** (Import).
6. Нажмите **"Обзор"** и выберите первый файл сертификата из папки `~/Загрузки/Certs_mincifra/`.
7. В появившемся окне **обязательно** поставьте галочку **"Доверять этому центру сертификации для идентификации веб-сайтов"** (Trust this certificate for identifying websites).
8. Нажмите OK.
9. Повторите шаги 5-8 для всех файлов:
   - `russian_trusted_root_ca_pem.crt`
   - `russian_trusted_root_ca_gost_2025_pem.crt`
   - `russian_trusted_sub_ca_pem.crt`
   - `russian_trusted_sub_ca_2024_pem.crt`
   - `russian_trusted_sub_ca_gost_2025_pem.crt`
10. Закройте окно настроек.
11. Полностью перезапустите браузер.

### Mozilla Firefox

Firefox использует собственное хранилище сертификатов, поэтому его нужно настраивать отдельно.

#### Инструкция для Firefox:

1. Откройте Firefox.
2. Нажмите на кнопку меню (три полоски в правом верхнем углу).
3. Выберите "Настройки" (Settings).
4. В левой панели выберите "Приватность и защита" (Privacy & Security).
5. Прокрутите страницу вниз до раздела "Сертификаты" (Certificates).
6. Нажмите кнопку "Просмотр сертификатов..." (View Certificates...).
7. Перейдите на вкладку "Центры сертификации" (Authorities).
8. Нажмите кнопку "Импортировать..." (Import...).
9. Выберите файл `russian_trusted_root_ca_pem.crt` из папки `~/Загрузки/Certs_mincifra/`.
10. В появившемся окне **обязательно** установите галочку "Доверять при идентификации веб-сайтов" (Trust this CA to identify websites).
11. Нажмите OK.
12. Повторите шаги 8-11 для каждого из следующих файлов:
    - `russian_trusted_root_ca_gost_2025_pem.crt`
    - `russian_trusted_sub_ca_pem.crt`
    - `russian_trusted_sub_ca_2024_pem.crt`
    - `russian_trusted_sub_ca_gost_2025_pem.crt`
13. Закройте окно "Certificate Manager" (Диспетчер сертификатов).
14. Закройте окно настроек.
15. Полностью перезапустите Firefox (закройте все окна и откройте заново).

## Часть 4. Удаление сертификатов из браузеров

Если вы хотите полностью удалить сертификаты (например, если они больше не нужны), их нужно удалять отдельно из каждого браузера.

### Удаление из Chromium-браузеров

1. Откройте настройки сертификатов: `chrome://settings/certificates` (или аналогичный адрес для вашего браузера).
2. Перейдите на вкладку **"Центры сертификации"** (Authorities).
3. Найдите в списке сертификаты с названиями, содержащими "Russian Trusted Root" или "Russian Trusted Sub".
4. Выберите каждый из них и нажмите **"Удалить"** (Delete).
5. Подтвердите удаление.
6. Закройте окно настроек и перезапустите браузер.

### Удаление из Firefox

1. Откройте Firefox.
2. Нажмите на кнопку меню (три полоски) -> "Настройки".
3. Выберите "Приватность и защита".
4. Прокрутите до раздела "Сертификаты" и нажмите "Просмотр сертификатов...".
5. Перейдите на вкладку **"Центры сертификации"** (Authorities).
6. Найдите в списке сертификаты с названиями, содержащими "Russian Trusted Root" или "Russian Trusted Sub".
7. Выберите каждый из них и нажмите **"Удалить"** (Delete) или **"Delete or Distrust"**.
8. Подтвердите удаление.
9. Закройте все окна и перезапустите Firefox.

## Часть 5. Проверка работоспособности

Для проверки корректности установки сертификатов откройте любой защищенный сайт, который ранее выдавал ошибку безопасности, например:

- https://www.gosuslugi.ru
- https://www.sberbank.ru
- https://www.minsifra.ru

Если сайт открывается без предупреждений о недействительном сертификате, установка выполнена правильно.

## Часть 6. Дополнительная информация

### Что означают названия файлов:

- **root_ca** — корневой центр сертификации, самый главный сертификат.
- **sub_ca** — промежуточный центр сертификации, подписывается корневым.
- **gost_2025** — сертификат, использующий российский стандарт шифрования ГОСТ.

### Если сайт всё ещё выдаёт ошибку:

1. Проверьте системное время и дату — сертификаты могут не работать, если время на компьютере сильно расходится с реальным.
2. Очистите кэш браузера или откройте сайт в режиме инкогнито.
3. Убедитесь, что вы импортировали все файлы, включая промежуточные (sub_ca).
4. Перезапустите браузер полностью (закройте все окна, а не только текущую вкладку).

### Разница между системной и ручной установкой:

- **Системная установка** — сертификаты видны всем приложениям в системе, включая все браузеры на Chromium. Это удобно, если используете много браузеров.
- **Ручная установка в браузеры** — сертификаты видны только в конкретном браузере, куда вы их импортировали. Это дает больше контроля, но требует повторять действия для каждого браузера.
