# Структуры в Go

## Введение

Структуры (struct) в Go — это составные типы данных, которые позволяют группировать связанные поля вместе. Они являются основой для создания моделей данных в Go-программах. В этой статье мы разберем различные способы работы со структурами, от базового объявления до создания функций-конструкторов и методов.

---

## 1. Базовое объявление структур

Структура объявляется с помощью ключевого слова `type` и содержит набор полей с их типами.

### Пример 1: Простая структура

```go
package main

import "fmt"

// Объявляем структуру Vertex с двумя полями
// Поля: X и Y, оба типа int
type Vertex struct {
    X int  // координата X
    Y int  // координата Y
}

// Объявляем структуру Person с тремя полями
type Person struct {
    Name string  // имя человека
    Age  int     // возраст человека
    City string  // город проживания
}

func main() {
    // Создаем экземпляр Vertex.
    // Поля заполняются в порядке объявления: X=1, Y=2
    fmt.Println(Vertex{1, 2})
    
    // Создаем экземпляр Person.
    // Указываем имена полей (рекомендуемый способ) — так понятнее и не зависит от порядка
    fmt.Println(Person{Name: "Alice", Age: 30, City: "Moscow"})
}
```

**Вывод:**
```
{1 2}
{Alice 30 Moscow}
```

## 2. Функции для работы со структурами

### 2.1. Функция для вывода структуры

Создадим отдельную функцию, которая выводит структуру в удобочитаемом формате.

**Важное объяснение: `p Person`**

```go
func printPerson(p Person) {
    //                 ^^^^^^
    //                 p — это ИМЯ ПАРАМЕТРА (переменная внутри функции)
    //                 Person — это ТИП ДАННЫХ (структура)
    //
    // Когда мы пишем p Person, мы говорим:
    // "Функция printPerson принимает один параметр.
    //  Этот параметр называется p.
    //  Его тип — Person (наша структура).
    //  Внутри функции мы можем обращаться к полям p через точку: p.Name, p.Age, p.City"
}
```

**Как это работает в коде:**

```go
package main

import "fmt"

// Объявляем структуру Person
type Person struct {
    Name string  // имя
    Age  int     // возраст
    City string  // город
}

// Отдельная функция для вывода Person.
// Параметр p — это КОПИЯ структуры Person.
// Внутри функции мы работаем с этой копией.
func printPerson(p Person) {
    // p.Name — обращаемся к полю Name структуры, переданной в функцию
    fmt.Println("Имя:", p.Name)
    // p.Age — обращаемся к полю Age
    fmt.Println("Возраст:", p.Age)
    // p.City — обращаемся к полю City
    fmt.Println("Город:", p.City)
}

func main() {
    // Создаем структуру alice
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    
    // Вызываем функцию printPerson.
    // Мы ПЕРЕДАЁМ копию структуры alice в параметр p.
    // Внутри функции p — это копия alice.
    printPerson(alice)
}
```

**Вывод:**
```
Имя: Alice
Возраст: 30
Город: Moscow
```

**Объяснение:**
- `p Person` означает: "параметр с именем `p` типа `Person`"
- При вызове `printPerson(alice)` мы передаем в функцию копию структуры
- Внутри функции `p` хранит эту копию, и мы работаем с ней
- Изменения `p` внутри функции НЕ влияют на оригинальную `alice`, потому что это копия

### 2.2. Функция, возвращающая строковое представление структуры

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Функция personInfo принимает структуру Person (параметр p)
// и возвращает строку с её содержимым.
// Обрати внимание: возвращаемый тип — string
func personInfo(p Person) string {
    // fmt.Sprintf форматирует строку и ВОЗВРАЩАЕТ её.
    // В отличие от fmt.Printf, которая печатает сразу на экран.
    // Мы используем p.Name, p.Age, p.City для доступа к полям.
    return fmt.Sprintf("Person{Name: %s, Age: %d, City: %s}", 
                       p.Name, p.Age, p.City)
}

func main() {
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    
    // personInfo возвращает строку, которую мы передаем в fmt.Println
    fmt.Println(personInfo(alice))
}
```

**Вывод:**
```
Person{Name: Alice, Age: 30, City: Moscow}
```

## 3. Функции-конструкторы

В Go нет встроенных конструкторов, но их можно легко создать с помощью обычных функций.

### 3.1. Простой конструктор

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Функция-конструктор.
// Принимает значения для каждого поля и возвращает готовую структуру.
// Название newPerson — распространённое соглашение в Go (new + имя типа)
func newPerson(name string, age int, city string) Person {
    // Здесь мы создаем структуру с переданными значениями.
    // Можно было бы написать:
    // var p Person
    // p.Name = name
    // p.Age = age
    // p.City = city
    // return p
    // 
    // Но короче сделать так:
    return Person{Name: name, Age: age, City: city}
}

func main() {
    // Создаем Person через конструктор.
    // Это удобно, потому что конструктор может содержать логику создания.
    alice := newPerson("Alice", 30, "Moscow")
    fmt.Println(alice)
}
```

**Вывод:**
```
{Alice 30 Moscow}
```

---

### 3.2. Конструктор с валидацией

```go
package main

import "fmt"

type Person struct {
    Name string  // имя
    Age  int     // возраст
    City string  // город
}

// Конструктор с валидацией (проверкой данных).
// Здесь мы гарантируем, что возраст всегда в разумных пределах,
// а город не пустой.
func newPerson(name string, age int, city string) Person {
    // Проверка возраста: если отрицательный → ставим 0
    if age < 0 {
        age = 0
    }
    // Проверка возраста: если больше 150 → ставим 150
    if age > 150 {
        age = 150
    }
    
    // Проверка города: если пустая строка → ставим "Unknown"
    if city == "" {
        city = "Unknown"
    }
    
    // Возвращаем структуру с проверенными данными
    return Person{Name: name, Age: age, City: city}
}

func main() {
    // Нормальный случай
    alice := newPerson("Alice", 30, "Moscow")
    fmt.Println(alice) // {Alice 30 Moscow}
    
    // Некорректные данные — конструктор их исправляет
    bob := newPerson("Bob", -5, "")              // возраст исправлен на 0, город на "Unknown"
    fmt.Println(bob) // {Bob 0 Unknown}
    
    john := newPerson("John", 200, "New York")   // возраст исправлен на 150
    fmt.Println(john) // {John 150 New York}
}
```

**Вывод:**
```
{Alice 30 Moscow}
{Bob 0 Unknown}
{John 150 New York}
```

### 3.3. Конструктор с указателем

Иногда удобнее возвращать указатель на структуру, а не копию. Это эффективнее для больших структур и позволяет изменять оригинал.

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Конструктор возвращает УКАЗАТЕЛЬ на Person.
// *Person — это тип "указатель на Person".
// &Person{...} — создает структуру и возвращает её адрес в памяти.
func newPerson(name string, age int, city string) *Person {
    // Проверка данных
    if age < 0 {
        age = 0
    }
    // &Person — возвращаем адрес структуры
    return &Person{Name: name, Age: age, City: city}
}

func main() {
    // alice — это УКАЗАТЕЛЬ на Person (*Person)
    alice := newPerson("Alice", 30, "Moscow")
    
    // В Go можно обращаться к полям через указатель без явного разыменования.
    // Компилятор автоматически делает (*alice).Name, но мы пишем просто alice.Name
    fmt.Println(alice.Name)   // Alice (автоматическое разыменование)
    fmt.Println(alice.Age)    // 30
    fmt.Println(alice.City)   // Moscow
    
    // Изменяем поле через указатель.
    // Так как alice — это указатель, изменение влияет на оригинал.
    alice.Age = 31
    fmt.Println(alice.Age)    // 31
}
```

**Объяснение:**
- `*Person` — указатель на структуру. Это значит, что переменная хранит не саму структуру, а адрес в памяти, где она лежит.
- `&Person{...}` — оператор `&` берёт адрес созданной структуры.
- В Go можно писать `alice.Name` вместо `(*alice).Name` — компилятор сам разыменовывает указатель.
- Изменения через указатель влияют на оригинальную структуру.

---

### 3.4. Сравнение: значение vs указатель

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
}

// Функция, которая изменяет КОПИЮ — оригинал не меняется
func setAgeCopy(p Person, newAge int) {
    p.Age = newAge  // меняем копию
    // оригинал не изменится!
}

// Функция, которая изменяет через УКАЗАТЕЛЬ — оригинал меняется
func setAgePointer(p *Person, newAge int) {
    p.Age = newAge  // меняем оригинал через указатель
}

func main() {
    alice := Person{Name: "Alice", Age: 30}
    
    // Передаём КОПИЮ — alice не изменится
    setAgeCopy(alice, 40)
    fmt.Println("После setAgeCopy:", alice.Age) // 30 (не изменилось!)
    
    // Передаём УКАЗАТЕЛЬ — alice изменится
    setAgePointer(&alice, 40)
    fmt.Println("После setAgePointer:", alice.Age) // 40 (изменилось!)
}
```

**Вывод:**
```
После setAgeCopy: 30
После setAgePointer: 40
```

## 4. Методы структур

Кроме обычных функций, можно создавать методы, привязанные к структуре. Это как функции, но они вызываются через точку: `alice.String()`.

### 4.1. Метод с получателем-значением

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Метод с получателем-значением (p Person).
// Это значит, что метод получает КОПИЮ структуры.
// Метод НЕ может изменять оригинал.
func (p Person) String() string {
    // p — это копия. Мы читаем поля и возвращаем строку.
    return fmt.Sprintf("%s (%d) из %s", p.Name, p.Age, p.City)
}

func main() {
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    
    // Вызываем метод через точку.
    // Go автоматически передает alice как p (по значению).
    fmt.Println(alice.String()) // Alice (30) из Moscow
}
```

**Вывод:**
```
Alice (30) из Moscow
```

---

### 4.2. Метод с получателем-указателем

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Метод с получателем-указателем (p *Person).
// Это значит, что метод получает УКАЗАТЕЛЬ на структуру.
// Метод МОЖЕТ изменять оригинал.
func (p *Person) Birthday() {
    // p — указатель. p.Age — это (*p).Age (автоматическое разыменование)
    p.Age++  // увеличиваем возраст
}

// Метод с получателем-указателем, изменяет город
func (p *Person) MoveTo(city string) {
    p.City = city  // меняем город
}

func main() {
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    
    // Вызываем методы с указателем.
    // Go автоматически передает &alice (адрес alice)
    alice.Birthday()   // Age: 30 → 31
    alice.MoveTo("London")  // City: "Moscow" → "London"
    
    fmt.Println(alice.String()) // Alice (31) из London
}
```

**Вывод:**
```
Alice (31) из London
```

---

### 4.3. Когда использовать значение, а когда указатель?

| Получатель | Что передаётся | Может изменять? | Когда использовать |
|-----------|---------------|-----------------|-------------------|
| `(p Person)` | Копия структуры | ❌ Нет | Для маленьких структур, только чтение |
| `(p *Person)` | Указатель на структуру | ✅ Да | Для больших структур, для изменения |

## 5. Полный пример с разными функциями

```go
package main

import "fmt"

type Person struct {
    Name string  // имя
    Age  int     // возраст
    City string  // город
}

// 1. Функция вывода на экран.
// Принимает КОПИЮ Person и печатает поля.
func printPerson(p Person) {
    fmt.Printf("Имя: %s, Возраст: %d, Город: %s\n", p.Name, p.Age, p.City)
}

// 2. Функция возврата строки.
// Принимает КОПИЮ Person и возвращает строку.
func personToString(p Person) string {
    return fmt.Sprintf("%s (%d) из %s", p.Name, p.Age, p.City)
}

// 3. Функция-конструктор.
// Создает и возвращает Person.
func newPerson(name string, age int, city string) Person {
    // Простая валидация
    if age < 0 {
        age = 0
    }
    return Person{Name: name, Age: age, City: city}
}

// 4. Метод структуры с получателем-значением.
// Возвращает строку с информацией.
func (p Person) Info() string {
    return fmt.Sprintf("Person{Name: %s, Age: %d, City: %s}", p.Name, p.Age, p.City)
}

// 5. Метод с получателем-указателем.
// Изменяет возраст.
func (p *Person) SetAge(newAge int) {
    if newAge >= 0 && newAge <= 150 {
        p.Age = newAge
    }
}

func main() {
    // Создаем структуру через конструктор
    alice := newPerson("Alice", 30, "Moscow")
    
    // Вывод разными способами
    printPerson(alice)                       // Имя: Alice, Возраст: 30, Город: Moscow
    fmt.Println(personToString(alice))       // Alice (30) из Moscow
    fmt.Println(alice.Info())                // Person{Name: Alice, Age: 30, City: Moscow}
    
    // Изменяем через метод
    alice.SetAge(31)
    fmt.Println(alice.Info())                // Person{Name: Alice, Age: 31, City: Moscow}
}
```

## 6. Итоговое резюме

1. **Структуры** — это способ группировки связанных данных.

2. **Поля** структуры доступны через точку `.`:
   ```go
   p.Name  // доступ к полю Name
   p.Age   // доступ к полю Age
   ```

3. **Параметры функций**:
   - `p Person` — параметр `p` типа `Person` (передаётся копия)
   - `p *Person` — параметр `p` типа "указатель на Person" (передаётся адрес)

4. **Конструкторы** — это функции, которые создают структуры с валидацией.

5. **Методы** — функции, привязанные к структуре:
   - `func (p Person) Method()` — получает копию (только чтение)
   - `func (p *Person) Method()` — получает указатель (можно изменять)

6. **Указатели** эффективны для больших структур и для изменения данных.

---

## Заключение

Работа со структурами в Go проста и гибка. Ключевое понимание — разница между:

- **Значением** (`Person`) — передаётся копия, оригинал не меняется
- **Указателем** (`*Person`) — передаётся адрес, оригинал можно менять

Выбор между `p Person` и `p *Person` зависит от задачи:
- Нужно только прочитать данные → используй `Person`
- Нужно изменить данные или структура большая → используй `*Person`
