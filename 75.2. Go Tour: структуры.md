# Структуры в Go

## Введение

Структуры (struct) в Go — это составные типы данных, которые позволяют группировать связанные поля вместе. Они являются основой для создания моделей данных в Go-программах. В этой статье мы разберем различные способы работы со структурами, от базового объявления до создания функций-конструкторов и методов.

---

## 1. Базовое объявление структур

Структура объявляется с помощью ключевого слова `type` и содержит набор полей с их типами.

### Пример 1: Простая структура

```go
package main

import "fmt"

type Vertex struct {
    X int
    Y int
}

type Person struct {
    Name string
    Age  int
    City string
}

func main() {
    fmt.Println(Vertex{1, 2})
    fmt.Println(Person{Name: "Alice", Age: 30, City: "Moscow"})
}
```

**Вывод:**
```
{1 2}
{Alice 30 Moscow}
```

**Объяснение:**
- `Vertex` — структура с двумя полями `X` и `Y` типа `int`
- `Person` — структура с тремя полями: `Name` (string), `Age` (int), `City` (string)
- В `main()` мы создаем экземпляры структур и выводим их
- При создании `Vertex{1, 2}` поля заполняются в порядке объявления
- При создании `Person{Name: "Alice", ...}` мы указываем имена полей (рекомендуемый способ)

## 2. Функции для работы со структурами

### 2.1. Функция для вывода структуры

Создадим отдельную функцию, которая выводит структуру в удобочитаемом формате:

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Отдельная функция для вывода Person
func printPerson(p Person) {
    fmt.Println("Имя:", p.Name)
    fmt.Println("Возраст:", p.Age)
    fmt.Println("Город:", p.City)
}

func main() {
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    printPerson(alice) // вызываем нашу функцию
}
```

**Вывод:**
```
Имя: Alice
Возраст: 30
Город: Moscow
```

**Объяснение:**
- Функция `printPerson` принимает параметр `p` типа `Person`
- Внутри функции мы используем оператор `.` для доступа к полям структуры
- Такая функция инкапсулирует логику вывода, делая код более читаемым
- Мы можем легко изменить формат вывода, не меняя код в `main()`

### 2.2. Функция, возвращающая строковое представление структуры

Иногда нужно не выводить структуру сразу, а получить её строковое представление для дальнейшего использования:

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Функция возвращает строковое представление Person
func personInfo(p Person) string {
    return fmt.Sprintf("Person{Name: %s, Age: %d, City: %s}", p.Name, p.Age, p.City)
}

func main() {
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    fmt.Println(personInfo(alice))
}
```

**Вывод:**
```
Person{Name: Alice, Age: 30, City: Moscow}
```

**Объяснение:**
- `personInfo` возвращает `string`, а не выводит её сразу
- Мы используем `fmt.Sprintf` для форматирования строки (аналог `Printf`, но с возвратом строки)
- Преимущество: строку можно сохранить в переменную, отправить по сети, записать в файл и т.д.
- Функция может быть использована в разных контекстах

## 3. Функции-конструкторы

В Go нет встроенных конструкторов, но их можно легко создать с помощью обычных функций.

### 3.1. Простой конструктор

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Функция-конструктор (создает Person)
func newPerson(name string, age int, city string) Person {
    return Person{Name: name, Age: age, City: city}
}

func main() {
    alice := newPerson("Alice", 30, "Moscow")
    fmt.Println(alice)
}
```

**Вывод:**
```
{Alice 30 Moscow}
```

**Объяснение:**
- Функция `newPerson` принимает значения для всех полей и возвращает структуру
- Имя функции начинается с `new` — это распространённое соглашение в Go
- Конструктор инкапсулирует логику создания структуры
- Если в будущем добавятся новые поля, нужно будет обновить только конструктор

### 3.2. Конструктор с валидацией

Улучшим конструктор, добавив проверку данных:

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Конструктор с валидацией
func newPerson(name string, age int, city string) Person {
    // Валидация возраста
    if age < 0 {
        age = 0
    }
    if age > 150 {
        age = 150
    }
    
    // Пустой город заменяем на "Unknown"
    if city == "" {
        city = "Unknown"
    }
    
    return Person{Name: name, Age: age, City: city}
}

func main() {
    alice := newPerson("Alice", 30, "Moscow")
    bob := newPerson("Bob", -5, "")  // некорректные данные
    john := newPerson("John", 200, "New York")  // некорректный возраст
    
    fmt.Println(alice)
    fmt.Println(bob)
    fmt.Println(john)
}
```

**Вывод:**
```
{Alice 30 Moscow}
{Bob 0 Unknown}
{John 150 New York}
```

### 3.3. Конструктор с указателем

Иногда удобнее возвращать указатель на структуру, чтобы избежать копирования:

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Конструктор возвращает указатель
func newPerson(name string, age int, city string) *Person {
    // Можно добавить валидацию
    if age < 0 {
        age = 0
    }
    return &Person{Name: name, Age: age, City: city}
}

func main() {
    alice := newPerson("Alice", 30, "Moscow")
    
    // Доступ к полям через указатель автоматически разыменовывается
    fmt.Println(alice.Name)   // Alice
    fmt.Println(alice.Age)    // 30
    fmt.Println(alice.City)   // Moscow
    
    // Изменяем поле через указатель
    alice.Age = 31
    fmt.Println(alice.Age)    // 31
}
```

**Объяснение:**
- `*Person` — указатель на структуру
- `&Person{...}` — создаёт структуру и возвращает её адрес
- В Go можно обращаться к полям через указатель без явного разыменования (`alice.Name`, а не `(*alice).Name`)

---

## 4. Сравнение различных подходов

| Подход | Преимущества | Когда использовать |
|--------|--------------|-------------------|
| Функция вывода | Инкапсулирует логику вывода | Для отладки, логирования |
| Функция возврата строки | Гибкость использования | Для сериализации, логирования |
| Конструктор (значение) | Простота, безопасность | Для небольших структур |
| Конструктор (указатель) | Эффективность, возможность изменения | Для больших структур |

## 5. Методы структур

Кроме обычных функций, можно создавать методы, привязанные к структуре:

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// Метод с получателем-значением
func (p Person) String() string {
    return fmt.Sprintf("%s (%d) из %s", p.Name, p.Age, p.City)
}

// Метод с получателем-указателем (может изменять структуру)
func (p *Person) Birthday() {
    p.Age++
}

func (p *Person) MoveTo(city string) {
    p.City = city
}

func main() {
    alice := Person{Name: "Alice", Age: 30, City: "Moscow"}
    
    fmt.Println(alice.String()) // Alice (30) из Moscow
    
    alice.Birthday()
    alice.MoveTo("London")
    
    fmt.Println(alice.String()) // Alice (31) из London
}
```

**Объяснение:**
- Методы определяются с помощью `func (p Person)` или `func (p *Person)`
- Методы с указателем могут изменять структуру
- Методы со значением получают копию структуры

## 6. Полный пример с разными функциями

```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
    City string
}

// 1. Функция вывода
func printPerson(p Person) {
    fmt.Printf("Имя: %s, Возраст: %d, Город: %s\n", p.Name, p.Age, p.City)
}

// 2. Функция возврата строки
func personToString(p Person) string {
    return fmt.Sprintf("%s (%d) из %s", p.Name, p.Age, p.City)
}

// 3. Функция-конструктор
func newPerson(name string, age int, city string) Person {
    return Person{Name: name, Age: age, City: city}
}

// 4. Метод структуры
func (p Person) Info() string {
    return fmt.Sprintf("Person{Name: %s, Age: %d, City: %s}", p.Name, p.Age, p.City)
}

func main() {
    // Создаем структуру через конструктор
    alice := newPerson("Alice", 30, "Moscow")
    
    // Вывод разными способами
    printPerson(alice)                    // Имя: Alice, Возраст: 30, Город: Moscow
    fmt.Println(personToString(alice))    // Alice (30) из Moscow
    fmt.Println(alice.Info())             // Person{Name: Alice, Age: 30, City: Moscow}
}
```

## 7. Итоговое резюме

1. **Структуры** — это способ группировки связанных данных
2. **Поля** структуры доступны через точку `.`
3. **Отдельные функции** могут принимать структуры как параметры
4. **Конструкторы** создают структуры с валидацией и логикой инициализации
5. **Методы** позволяют привязать функции к типам структур
6. **Указатели** на структуры эффективны для больших данных и при необходимости изменения

## Заключение

Работа со структурами в Go проста и гибка. Вы можете создавать функции для работы со структурами разными способами:
- Функции для вывода
- Функции для преобразования в строку
- Функции-конструкторы
- Методы структур
