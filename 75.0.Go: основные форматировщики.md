
## Основные форматировщики в Go

| Verb | Описание | Пример |
|------|----------|--------|
| `%v` | Значение в формате по умолчанию | `false`, `42`, `(2+3i)` |
| `%T` | Тип значения | `bool`, `int`, `complex128` |
| `%d` | Десятичное целое число | `42` |
| `%s` | Строка | `"hello"` |
| `%f` | Число с плавающей точкой | `3.141590` |
| `%t` | Логическое значение (true/false) | `true` |
| `%q` | Строка в кавычках | `"hello"` |
| `%#v` | Значение в Go-синтаксисе | `false`, `[]int{1,2}` |

## Примеры разных форматировщиков

```go
x := 42
fmt.Printf("%v\n", x)   // → 42
fmt.Printf("%T\n", x)   // → int
fmt.Printf("%d\n", x)   // → 42
fmt.Printf("%b\n", x)   // → 101010 (двоичное)
fmt.Printf("%x\n", x)   // → 2a (шестнадцатеричное)

s := "hello"
fmt.Printf("%v\n", s)   // → hello
fmt.Printf("%T\n", s)   // → string
fmt.Printf("%q\n", s)   // → "hello"
```

## Почему именно так?

**`%T`** — от слова **Type** (тип)
**`%v`** — от слова **Value** (значение)

Это соглашение в Go: "T" для типа, "v" для значения.

## Важно: порядок аргументов

```go
fmt.Printf("Type: %T Value: %v\n", ToBe, ToBe)
//                               1-й    2-й
//                               %T     %v
```

**Первый аргумент** после строки формата идет к первому `%` (который `%T`), **второй** — ко второму `%` (который `%v`).

Если поменять местами:
```go
fmt.Printf("Type: %v Value: %T\n", ToBe, ToBe)
// → "Type: false Value: bool"  (перепутали!)
```
